# 推薦ルールのテスト

Node.jsがある環境で、プロジェクトのルートから実行します。追加パッケージは不要です。

```sh
node tests/recommendation.test.cjs
node tests/app-features.test.cjs
```

2026-11-01の昼を固定の現在日時として、実際のrecommendation.jsとscript.js内の計算関数を読み込んでテストします。利用者のlocalStorageを読んだり書き換えたりしません。

対象は当日・過去の締切、手動予定日、親子と分類、締切の継承・解除、開始日・スコア・グラフの一致、進捗100％の完了確認、元の配点・作業規模、JSON往復、日曜の境界など28件です。

今回の実行環境にはNode.jsがないため、同じテスト関数をV8環境で実行しました。Node CLIの起動そのもの、ブラウザー実機・スクリーンリーダー・性能の確認とは区別しています。

app-features.test.cjsは副作用をモックしたDOM・保存領域で、子締切の初期入力・上書き・旧データ、各画面からのメニュー遷移、親子のメモ・再読み込み・バックアップ復元・保存失敗と下書き、案内バナーの端末／PWA条件・非表示設定を検証します。実際のブラウザーレンダリングやOSのインストール画面を再現するテストではありません。

## 一般公開前の修正テスト

既存51件に、公開前の5件の不具合に対する回帰テスト40件を追加しています（合計91件）。Blobのモックも文字数ではなくUTF-8バイト数を数えるようにしています。

- 出力・復元の両方で5MiBの直前・ちょうど・直後を確認。英数字と日本語の両方を使い、出力できた境界のバックアップを復元して本文を比較します。
- 親・子、分類、予定日、進捗、移行取消情報、メモ、過去の振り返りを含むバックアップ往復を確認します。
- 子追加の再開と親の保持、別の親への切替確認、登録後の独立タスクを確認します。
- 5MiBの模擬保存領域で復元を失敗させ、元データ・過去の退避の維持と、失敗後の通常保存を確認します。
- 追加・編集の離脱警告、編集破棄の確認、画面移動、pagehide・非表示からの入力再開、一時退避失敗時の通常保存を確認します。
- 検索、締切あり・なし、分類、グラフからの絞り込みと、親子表示・件数を確認します。
- 作成・編集・削除・完了・取消・移行と旧データの保護も確認します。推薦式は変更しません。

入力途中は保存済みタスクと別のsessionStorageキーへ一時退避します。同じタブの再読み込みに備える補助で、タブの終了やスマホの強制終了からの復旧を保証するものではありません。通常の保存ボタンとバックアップが必要です。

保存領域が不足する場合、復元前の保護を省いて復元を強行しません。元データをファイルに控えたうえで、空き容量のある別のブラウザー・端末で復元してください。元のサイトデータを削除する必要はありません。

### スマホ実機での最終確認

実データを使わず、テスト用タスクを作って次を確認してください。

1. Safari・Chromeとホーム画面アプリで、追加途中を閉じて再開し、子の親・締切が残ることを確認。
2. 編集中にキャンセル・Escapeを操作し、破棄の確認を拒否すると入力が残ることを確認。
3. 入力中に別アプリへ移動して戻る場合と、同じタブを再読み込みする場合を確認。一時退避が使えない設定でも、保存済みタスクが維持されることを確認。
4. 未保存のタスクメモがある状態でバックアップの警告を確認。保存後に控えを作り直し、実ファイルの保存・読み込みと内容の一致を確認。
5. 検索・分類・締切条件とグラフからの絞り込みで、表示される子と件数を確認。
6. PWA更新を適用し、オンライン・機内モードの両方で起動・保存・再起動を確認。

実ファイルの共有・ダウンロード、ブラウザー実際の容量制限、ソフトウェアキーボード、OSによる強制終了、PWA更新はモックテストだけでは検証できません。
